# Email Ledger

在 Chrome 里登记自己的邮箱。一个邮箱一条记录，用来区分现在能不能用、有没有付费，并查看邮箱注册日、Claude 注册日，以及从 Claude 注册当天算起过了多少天。

不保存密码，也不自动登录或自动判断账号状态。

## 本地运行

先构建，再加载。

```bash
npm run build
```

1. 打开 `chrome://extensions`。
2. 打开右上角的「开发者模式」。
3. 选择「加载已解压的扩展程序」，选中本目录。

Windows 和 Mac 要看到同一份清单，需要两边都加载这份代码，Chrome 登录同一个 Google 账号，并且打开同步。扩展编号写在 `manifest.json` 的 `key` 里，用来保证两边是同一个插件。

工具栏图标打开小窗口。记录多的时候，用窗口里的「打开完整页面」。导出的 JSON 可以再导入，作为备份。

## 检查

```bash
node --test
```
